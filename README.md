# Sultan Siddique Photography

Static portfolio site: plain HTML, CSS and JavaScript with no build step.

- `index.html`: home page (hero slideshow, collections, selected work)
- `appalachia.html`, `california.html`, `southwest.html`, `wildlife.html`, `small-wonders.html`: collection galleries with a lightbox
- `about.html`: about, gear and print ordering
- `img/l` (2000px) and `img/s` (800px): WebP images with camera metadata and GPS removed

Deploy: import this repository in Vercel as a static site (framework preset "Other", no build command, output directory `.`).
